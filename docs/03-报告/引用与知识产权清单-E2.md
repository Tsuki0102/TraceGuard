## 四、自研与原创声明

以下核心链路为本项目**原创设计与实现**（含参赛优化批次 A2/A4/B1/B2/A5/B3，见《优化方案-项目技术改进》）：
三维相似度模型（Sem/Con/Inv 加权 + 风险惩罚项）与去共线性结构不变量重构；风险门控双通道判定
（分数通道 OR 风险通道）；GAP-046 候选复核架构（优先级候选规划 + 探针升级补审）；FUN-04b LLM
双评审共识-仲裁-否决管线；判定溯源（judge_path/judge_detail 逐条落库）；缺陷行级定位候选评分排序
（DefectLocator v3）；文件内容哈希增量分析协议（解析 + 向量化两级复用）；评测体系（5 域 116 对
标注集、tune/validation 分离、LLM 盲评双评协议、三层 CI 指标门禁）。

## 五、合规说明

1. 全部第三方组件均为公开开源/免费组件，通过 Maven Central/npm 官方渠道引入，未修改其源码。
2. MySQL 服务端与 mysql-connector-j 为 GPL 系许可：本项目为内部部署应用场景，连接器的
   FOSS exception 覆盖 Apache-2.0 主程序的链接使用；若未来以混淆/闭源形式分发，建议改用
   MariaDB Connector/J（Apache-2.0）。
3. 各组件许可证以官方仓库最新声明为准；佐证材料中如需许可证全文，附官方 LICENSE 文件链接。
4. 算法实现参考的公开技术文献（形式化方法/LLM 判定/行级定位方向）在技术方案"参考文献"章节列出。
