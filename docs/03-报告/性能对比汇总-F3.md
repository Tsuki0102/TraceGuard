## 五、结论

1. 规则模式（默认部署形态）满足"千行 ≤2min / 万行 ≤10min"验收线且余量大（1.974s / 27.77s）。
2. 二次分析（增量）在 kilo 实测端到端 -76%；LLM 增强模式下收益随逐方法描述成本占比放大。
3. LLM 全链增强经候选复核收敛为"有界预算"（万行判定二审 ≈12min），从"不可扩展"转为"可工程化"。
4. 全部数据可复现：性能采集脚本（eval.PerformanceTest / scripts/b3_incr_quant.py）、执行记录
   （《优化方案-项目技术改进》）与原始日志均留档。
