**整体结论**: 千行级与万行级均满足性能基准要求（千行 ≤ 2min、万行 ≤ 10min）。
规则模式万行级瓶颈为 `runConsistencyCheck`（约 132.3s，占 94.6%）；
增强模式（本地 BGE）万行级瓶颈仍为 `runConsistencyCheck`（168.4s 占 66.1%），`embedSemantics`（BGE 向量化）占 21%，本地向量化不构成性能瓶颈；
LLM 全链路增强（2026-08-27 实测）kilo 耗时 3646.879s（≈60.8min），因对每条需求/方法/判定对做逐条 LLM 调用（431 次），与规则模式 5.086s 差异巨大——该数据如实记录 LLM 全量增强的真实成本，作为架构决策依据：生产须按 GAP-046「候选复核」仅对规则判定的候选缺陷对做 LLM 二审（万行保守上限 200 对），不得全量逐条增强。

## 5. 增强模式基准（FUN-06）

> 上述达标结论均为**规则模式**（llm.enabled=false、embedding 跳过）。SRS 性能指标未区分模式，
> 开启 LLM/Embedding 增强后的耗时需单独实测留档，避免结项答辩被质疑。

### 5.1 基准方法

- 同一 PerformanceTest（`eval.PerformanceTest`）可跑增强模式：
  - **本地 BGE Embedding 开启**：`traceguard.llm.embedding.provider=local`，`model-path` 指向下载的 ONNX 模型
    （执行 `scripts/download_bge_model.sh` 下载并写入 .env，或直接配置 `EMBEDDING_MODEL_PATH`）；
  - **本地 CodeLlama 开启**：`traceguard.llm.engine=langchain` + `provider=codellama`（需 Ollama，见 FUN-03）。
- 每次跑 kilo 级 3 次取中位数，结果写入 `性能基准报告-{kilo|tenk}.md` 的"增强模式"分节。

### 5.2 当前状态（如实记录）

| 模式 | 状态 | 说明 |
|---|---|---|
| 规则模式 | ✅ 已实测 | kilo 5.086s / tenk 139.935s（见第 3 节） |
| 本地 BGE 增强 | ✅ 已实测（kilo + tenk，2026-08-26 复测） | 模型已下载并验证（FUN-04①）；kilo 增强 **10.78s**、tenk 增强 **254.63s** 均达标，`embedSemantics`（BGE 向量化）分别占 45.8% / 21%，本地向量化不构成瓶颈（明细见 性能基准报告-{kilo\|tenk}.md） |
| 本地 LLM 增强 | ✅ 已实测完整性能基准（qwen2.5-coder:14b GPU，2026-08-27） | ①一致性判定端到端评测成功（LLM 成功 55/55=100%；缺陷检测指标已由 FUN-04b 双判定管线再提升——2026-08-27 在线实测 96.4%/3.8%/3.4% 三项全达标，见 FUN-04/评测报告）；②完整性能基准（kilo 全链路含一致性判定，单次数据采集）**total=3646.879s（≈60.8min）**，LLM 调用 **431 次全部成功（0 失败）**——需求增强 29 / 规约生成 29 / 代码逻辑描述 136 / 判定二审 200 / 缺陷解释 37；分阶段：parseCode 1445.93s（39.6%，136 次逐方法描述）> generateFormalSpecs 790.73s > parseRequirements 666.26s > runConsistencyCheck 425.75s（11.7%，≈2.1s/对）> generateDefects 305.39s > embedSemantics 12.76s。全量逐条 LLM 增强远超规则模式（5.086s），生产须按 GAP-046「候选复核」控制调用规模 |

**结论**：增强模式基准的方法与配置已齐备并全部实测：BGE 本地向量化增强（kilo 10.78s / tenk 254.63s）达标；本地 LLM 增强完整性能基准（kilo 3646.879s）已如实留档——**LLM 全量逐条增强远超规则模式（5.086s）**，印证生产必须采用 GAP-046「候选复核」架构（LLM 仅复核规则判定的候选缺陷对，万行保守上限 200 对 × ≈2.1s/对 ≈ 7min 二审预算），而非全量逐条增强。规则模式主验收口径不受影响（已达标且远优于阈值）。
