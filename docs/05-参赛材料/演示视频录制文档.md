# 规码同轨 · 产品介绍视频录制文档

> 赛题2「AI+软件创新」｜视频定位：**产品介绍片** —— 画面多扫界面、文案一句话一带而过
> 目标总长：**约 4 分 10 秒**（硬性区间 3–5 分钟）｜ 导出：MP4 / 1080p / ≤300MB
> 特色镜头：**Landing 产品封面页从头到尾完整走一遍**（该页为精心设计的展示门面）
> 节奏原则：每个界面 **3–8 秒**，旁白只给结论不给细节；细节留给答辩 PPT 与方案书

---

## 一、红线（开录前必读）

- 全片不得出现：校名、校徽、Logo、指导教师姓名、API Key（**不录大模型配置页**）
- 录屏用无痕窗口 + `Ctrl+Shift+B` 隐藏书签栏 + 系统勿扰 + 全屏（隐藏任务栏）
- 素材放中性路径（如 `D:\demo\`），避免文件对话框暴露个人信息
- 导出后核对：时长 3–5 分钟、≤300MB、清除文件属性元数据

## 二、录制前准备

- [ ] 后端 :8080 / 前端 :3000 / MySQL 正常；智能助手可对话（qwen3-max 链路）
- [ ] 演示账号登录（昵称非真实姓名）；已有分析结果的演示项目 ≥1 个
- [ ] 素材：`D:\demo\library-manager.zip`（Maven 工程）+ 需求文档 1 份
- [ ] 每镜单独录制、后期拼接；先录画面后配音
