## 二、全局设计规范

1. **数字口径唯一**：凡出现准确率/漏检/误报，一律 95.0% / 0.0% / 7.3%（验证集盲评）；如需提调参集或首测 96.4%，必须标注"tune 集/首测批次"字样；逻辑还原、性能数字同口径标注出处。
2. **图表规范**：图片统一深色字+浅底；每张图表下加来源脚注（如"数据：《评测报告-综合》A4 扩容复测 2026-09-03"）。
3. **配色**：与作品分享卡一致——深海军蓝 #0d1b2a / 亮蓝 #4da3ff / 结果绿 #3ddc97。
4. **版式**：每页字号下限 14pt；一页一论点；标题即结论（例如「双评审+规则仲裁：误报 27.6% → 7.3%」优于「创新点二」）。
5. **红线自查（提交前逐页过一遍）**：无校名/校徽/教师信息；截图里无真实密钥（API Key、JWT）；PDF 元数据作者字段清理；作品名 ≤20 字。
