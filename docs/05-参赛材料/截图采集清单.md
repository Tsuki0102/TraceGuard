## 三、注意事项

1. **红线**：截图不得含学校名称/校徽/指导教师信息；GitHub 截图注意仓库名旁边不要露出个人头像与昵称（可裁掉）；`.env` 密钥绝不入镜。
2. **口径**：截图里的指标必须与页面文字一致（95.0% / 0.0% / 7.3% / κ=0.8016，验证集盲评口径）；评测中心截图先跑一次复算让数字上屏。
3. **清晰度**：浏览器缩放 100%、窗口最大化后截全区，避免带书签栏；PNG 格式。
4. 演示数据：`powershell -ExecutionPolicy Bypass -File scripts\demo-seed.ps1`（电商订单样例，分析约 1-2 分钟），或用 `samples/` 下任一工程走完整流程。
