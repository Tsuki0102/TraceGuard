# 图书管理系统 - 需求规格说明书
# 版本: 1.0
# 日期: 2026-08-28

REQ-001: 图书入库时，必须校验图书标题不为空且馆藏数量大于0，否则入库失败并返回错误信息。
REQ-002: 读者注册时，必须校验姓名不为空且手机号为11位数字，否则注册失败并返回错误信息。
REQ-003: 借书时必须校验读者存在、图书存在且馆藏数量大于0，同时读者在借数量不得超过5本，任一条件不满足则拒绝借出。
REQ-004: 还书时必须校验借阅记录存在且尚未归还，归还成功后该书馆藏数量加1。
REQ-005: 续借时必须校验借阅记录存在且未逾期，已逾期的借阅记录不允许续借。
REQ-006: 逾期罚款按每本每天0.5元计算，罚款金额必须大于等于0。
REQ-007: 图书检索支持按关键词对书名进行模糊匹配，将关键词拼入查询语句执行检索并返回结果列表。
REQ-008: 借阅报表支持导出为文本文件，将全部借阅记录逐行写入目标文件。
REQ-009: 借书成功后，系统必须向读者发送借阅成功通知。
REQ-010: 还书成功后，系统必须向读者发送归还确认通知。
REQ-011: 支持读者预约已在借的图书，图书归还时按预约顺序通知预约读者。
REQ-012: 支持逾期自动发送催还短信提醒，每天定时扫描并通知逾期读者。
