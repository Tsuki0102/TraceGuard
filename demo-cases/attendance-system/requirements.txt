# 员工考勤管理系统 - 需求规格说明书
# 版本: 1.0
# 日期: 2026-08-29

REQ-001: 员工打卡时必须校验员工号存在于员工花名册中，员工号不存在时打卡失败并记录异常。
REQ-002: 每日首次打卡记为上班打卡，同一员工当日第二次打卡记为下班打卡，超过两次的打卡被拒绝。
REQ-003: 迟到判定规则：上班打卡时间超过09:00即记为迟到。
REQ-004: 提交请假申请时必须校验请假开始日期不晚于结束日期，日期范围非法时申请被拒绝。
REQ-005: 加班时长按小时为单位统计，每次加班登记必须记录加班日期与时长小时数。
REQ-006: 月度出勤统计需汇总指定月份内每位员工的出勤天数、迟到次数与加班总时长。
REQ-007: 支持导出指定月份的考勤月报为文本文件，包含每位员工的统计汇总。
REQ-008: 异常打卡记录必须转入人工审核队列，由管理员复核后处理。
