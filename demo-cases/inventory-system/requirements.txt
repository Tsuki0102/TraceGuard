# Inventory Management System - Software Requirements Specification
# Version: 1.0
# Date: 2026-08-31

REQ-001: 商品入库时必须校验商品名称不为空且库存数量大于0，否则入库失败并返回错误信息。
REQ-002: 商品出库时必须校验商品存在且库存充足，库存不足时拒绝出库并返回错误信息。
REQ-003: 修改商品信息时必须校验商品存在且价格大于0，否则修改失败并返回错误信息。
REQ-004: 库存预警：商品库存数量低于10时，系统必须将该商品标记为低库存状态。
REQ-005: 支持按商品名称关键词查询商品列表，查询关键词不能为空。
REQ-006: 支持统计指定商品的库存总量与库存金额总额。
REQ-007: 出库记录导出：支持将全部出库记录导出为文本文件。
REQ-008: 新增供应商时必须校验供应商名称不为空且联系电话为11位数字，否则新增失败并返回错误信息。
REQ-009: 商品出库时必须校验商品状态为在售状态，已下架商品拒绝出库。
REQ-010: 删除商品前必须校验商品库存为0，库存不为0时拒绝删除并返回错误信息。
