# 简易日志库 - 需求规格说明书（C++ 演示工程）
# 版本: 1.0
# 日期: 2026-09-21
# 说明: T11 多语言扩展演示用 C++ 工程（含 C 风格源文件），与 ecommerce-order/java、
#       python-inventory/python 口径一致；代码注入 5 类 C/C++ 特色基础缺陷信号
#       （malloc 泄漏 / fopen 句柄泄漏 / 危险函数 / malloc 未判空 / 裸 catch(...)）
#       与 1 处需求-代码一致性缺陷（落盘阈值条件反转）。

REQ-001: 日志初始化时必须校验日志文件路径不为空，路径为空时初始化失败并返回错误。
REQ-002: 支持三种日志级别 INFO/WARN/ERROR，写入日志时必须附带级别标识。
REQ-003: 每条日志必须包含时间戳，格式为 yyyy-MM-dd HH:mm:ss。
REQ-004: 日志写入时若内容长度超过 512 字节，必须截断至 512 字节后再写入。
REQ-005: 支持按关键字查询日志记录，查询不到时返回空结果。
REQ-006: 日志文件句柄在库关闭时必须关闭，不得遗留打开状态。
REQ-007: 关闭日志库时必须将内存缓冲区中未落盘的日志全部刷写到文件。
REQ-008: 日志缓冲区占用超过阈值（1024 字节）时必须自动触发落盘。
REQ-009: 统计功能：返回当前日志总条数。
REQ-010: 错误处理：任何文件操作失败时必须返回错误码，不允许静默忽略。
