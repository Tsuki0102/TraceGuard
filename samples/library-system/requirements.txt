# 图书借阅管理系统 - 需求规格说明书
# 版本: 1.0
# 日期: 2026-09-03

REQ-L001: 借书时，必须校验读者证在有效期内，读者证过期则拒绝借阅。
REQ-L002: 借书时，必须校验读者当前借阅数量，每人最多同时借阅5本，达到上限拒绝借阅。
REQ-L003: 借书时，必须校验图书库存大于0，无库存时拒绝借阅。
REQ-L004: 借书成功后，系统必须依次完成：扣减图书库存、生成借阅记录（含借出日期与应还日期）、更新读者在借数量。
REQ-L005: 借阅期限为30天，应还日期为借出日期加30天。
REQ-L006: 还书时，系统必须核对应还日期，逾期还书按0.5元/天计算逾期罚款，罚款计入读者欠款。
REQ-L007: 罚款封顶规则：单次逾期罚款最高不超过50元，超出部分不再累计。
REQ-L008: 还书成功后，必须增加图书库存并核销对应借阅记录（状态置为已归还）。
REQ-L009: 续借规则：每条借阅记录最多续借1次，续借将应还日期延长15天。
REQ-L010: 已被其他读者预约的图书不可续借，存在有效预约时续借请求必须拒绝。
REQ-L011: 信用规则：读者欠款总额超过10元时，冻结其借阅资格，冻结期间拒绝一切借书请求。
REQ-L012: 信用规则：读者有逾期未还图书超过15天时，冻结其借阅资格。
REQ-L013: 预约图书时，必须校验该书当前无库存（有库存时应直接借书而非预约），重复预约同一本书必须拒绝。
REQ-L014: 取消预约后，预约名额释放，可被其他读者预约。
REQ-L015: 支持按读者证号查询该读者的全部在借图书列表。
REQ-L016: 支持查询所有逾期未还的借阅记录，并按逾期天数从高到低排序。
REQ-L017: 统计功能：支持按图书分类统计当前借出数量。
REQ-L018: The system shall allow librarians to search books by ISBN and return the exact matching book, or null when no book is found.
REQ-L019: 挂失补办：读者证挂失后原证立即失效，补办新证后借阅资格与欠款记录转移到新证。
REQ-L020: 图书信息管理：新增图书时必须校验ISBN不为空且价格大于0。
REQ-L021: 系统支持基于借阅历史的个性化图书推荐，为读者推荐其未借阅过的同类图书。
REQ-L022: 系统支持将本月借阅排行榜导出为Excel文件，包含书名、作者、借出次数三列。
REQ-L023: 统计功能：支持统计指定读者累计借阅次数（含已归还的记录）。
REQ-L024: 支持判断某本图书当前是否存在有效预约，存在返回true，不存在返回false。
REQ-L025: 支持按作者名搜索图书，返回该作者的全部图书列表。
