# 任务执行器 - 需求规格说明书（Go 演示工程）
# 版本: 1.0
# 日期: 2026-09-21
# 说明: T11 多语言扩展演示用 Go 工程，与前序 Java/Python/C++ 工程口径一致；
#       代码注入 Go 特色基础缺陷信号（错误未处理/错误被 _ 丢弃/资源未释放/锁未释放/panic 滥用）
#       与 1 处需求-代码一致性缺陷（落盘阈值条件反转）。

REQ-001: 创建执行器时必须校验名称不为空，名称为空时返回错误。
REQ-002: 支持三种任务级别 INFO/WARN/ERROR，不同级别对应权重 1/2/3。
REQ-003: 任务大小支持带单位解析，非法输入必须返回错误而非崩溃。
REQ-004: 读取任务配置文件时必须检查读取错误，读取失败返回错误信息。
REQ-005: 加载远程配置文件后必须关闭文件句柄，所有路径下不得泄漏。
REQ-006: 并发计数更新必须保证线程安全，锁在函数返回前必须释放。
REQ-007: 关闭执行器时必须将内存缓冲刷写到日志。
REQ-008: 任务缓冲区超过阈值（100）时必须自动触发落盘。
REQ-009: 清理临时文件时的错误必须被记录，不允许静默丢弃。
REQ-010: 任何函数失败时必须以 error 返回，不允许以 panic 代替错误返回。
