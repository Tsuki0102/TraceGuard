# 电商订单管理系统 (ecommerce-order)

## 场景描述

本样本项目模拟一个电商订单管理系统的核心业务逻辑，包含订单创建、支付处理、库存管理、退款等典型电商场景。项目仅依赖 JDK 标准库，无第三方框架。

## 需求统计

- **需求总数**: 12 条 (REQ-001 ~ REQ-012)
- **覆盖范围**: 订单创建校验、状态流转、支付处理、库存管理、退款、取消、查询、统计

## 预期分析结果

分析工具应能检测出以下问题：

1. **资源泄漏** (D01): FileInputStream 未在 finally 中关闭
2. **超范围实现** (D02, D03): 积分赠送和批量导出功能不在需求中
3. **业务逻辑错误** (D04, D09, D11): 状态判断条件反转、退款金额多扣手续费、库存检查遗漏预留量
4. **空值校验缺失** (D05, D06, D12): 多处缺少 null 检查导致 NPE 风险
5. **异常处理不当** (D07): 空 catch 块吞掉异常
6. **越界访问** (D08): 空列表调用 get(0)
7. **状态流转违规** (D10): 跳过中间状态直接完成订单
