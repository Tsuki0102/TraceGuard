> python-inventory / cpp-loglib / go-taskrunner 为 T11 多语言扩展（2026-09-21）新增：创建项目时技术栈填
> `Python` / `C++`（或 `C`）/ `Go` 即自动路由到对应 tree-sitter 解析器，全流程（一致性校验/缺陷定位/
> 追溯矩阵/报告导出）与 Java 工程一致，无需改全局配置。

## 使用说明

1. **全流程分析**：将 `code/` 目录作为代码工程上传，`requirements.txt` 作为需求文档上传，启动分析任务。
2. **Ground Truth 比对**：每个工程附带 `defects.json`，记录已知缺陷的位置与类型，用于评测检出率/漏检率/误报率。
3. **编译约束**：所有代码仅依赖 JDK 标准库，保证 Soot 编译路径可用。
