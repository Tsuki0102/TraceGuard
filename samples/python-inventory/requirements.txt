# 仓库库存管理系统 - 需求规格说明书（Python 示例工程）
# 版本: 1.0
# 日期: 2026-09-21
# 说明: T11 多语言扩展演示用 Python 工程，与 ecommerce-order（Java）口径一致；
#       代码中注入了基础缺陷信号（可变默认参数/SQL拼接/资源未释放/死循环/裸except）
#       与需求-代码一致性缺陷（库存校验条件反转），供分析链路与评测使用。

REQ-001: 入库时必须校验入库数量大于0，否则拒绝入库并返回错误信息。
REQ-002: 入库时必须校验商品名称不为空，否则拒绝入库并返回错误信息。
REQ-003: 出库时必须先检查库存是否充足，库存不足时拒绝出库并返回错误信息。
REQ-004: 出库成功后必须扣减库存并记录操作时间，时间格式为 yyyy-MM-dd HH:mm:ss。
REQ-005: 支持按商品名称精确查询库存记录，查询不到时返回 None。
REQ-006: 支持查询全部库存清单，按入库顺序返回。
REQ-007: 系统日志必须写入 logs/inventory.log 文件，内容包含时间与操作类型。
REQ-008: 库存预警：商品库存低于阈值10时，状态标记为 warning。
REQ-009: 删除库存记录前必须先确认记录存在，记录不存在时返回错误信息。
REQ-010: 按月份统计入库总量，月份格式为 yyyy-MM。
